# tolkin-web

The Tolkin web app. A privacy-first AI token analyzer. Nothing leaves your browser. See [PLAN.md](./PLAN.md) for the full design and roadmap.

## Scripts

- `bun run dev` start the Next.js dev server (Turbopack)
- `bun run build` production build (Turbopack)
- `bun run start` serve the production build
- `bun run lint` Biome check
- `bun run lint:fast` oxlint speed gate
- `bun run format` Biome write
- `bun run typecheck` tsgo (TypeScript 7 beta) type check
